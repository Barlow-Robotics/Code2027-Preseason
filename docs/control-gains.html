4. Apply only the gains

Open src/main/java/first/robot/subsystems/Elevator.java. Find TODO 5.E4.

Find this code — red marks what changes


    // TODO 5.E4: Apply only the gains.
    @Override
    public void periodic() {
        // TODO 5.E5: Check for an Apply request.

Apply resets to off after each attempt. We reject invalid numbers and send only Slot0Configs: the sensor ratio and Motion Magic limits stay intact. A failed attempt is reported instead of retried every loop. The 0–1000 range is an input check, not a promise that every value will tune well.

Make it match — green marks the new code


    private void updateGains() {
        if (!applyGains.get()) {
            return;
        }
        applyGains.set(false);
        double[] values = {kP.get(), kD.get(), kG.get(), kV.get(), kA.get()};
        for (double value : values) {
            if (!Double.isFinite(value) || value < 0.0 || value > 1000.0) {
                gainStatus = "Not applied: use numbers from 0 to 1000";
                return;
            }
        }
        var next = new Slot0Configs();
        next.GravityType = appliedGains.GravityType;
        next.kP = values[0];
        next.kD = values[1];
        next.kG = values[2];
        next.kV = values[3];
        next.kA = values[4];
        var status = motor.getConfigurator().apply(next, 0.020);
        if (status.isOK()) {
            appliedGains = next;
            gainStatus = "Applied";
        } else {
            gainStatus = "Not applied: " + status + "; switch Apply on to retry";
        }
    }
