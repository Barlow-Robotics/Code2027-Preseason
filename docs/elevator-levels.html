Setup

What we will change

We will replace the two held-button controls with three named destinations: BOTTOM, MID, and TOP. Each tap selects the next destination. A movement command stays running until arrival, and interruption still replaces the old target with a hold.

This lesson uses the elevator. Both mechanisms are already present in the starting code. Leave the arm code unchanged.

Download the code and create your branch

Coach preview: the starting tag below exists locally but has not been published. Publish the starting tags and lesson pages before students follow these download steps.

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit any work you want to keep on your current branch before switching. Under Current branch, choose main.
  3. Click Fetch origin. If it changes to Pull origin, click that too.
  4. Open History. Find the commit named Express elevator motion limits in meters, marked with tag walkthrough-03-start. Its short identifier is 16d099e. This gives everyone the same starting code even after main changes.
  5. Right-click that commit and choose Create branch from commit. Name it lab/your-name-elevator-levels, replacing your-name with your name. Click Create branch.
  6. Open the Code2027-Preseason project using WPILib 2027 VS Code. Remember to open the top-level folder.
