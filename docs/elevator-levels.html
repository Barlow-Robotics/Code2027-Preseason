What are we building?

Tap Y to go up a level. Tap A to go down. The elevator keeps moving after you release.

Target: BOTTOM · Holding

or click the controller buttons.

Download the code and create your branch

Coach: publish before class

The starting branch is local only. Publish walkthrough/3 and these pages before students begin.

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit your current work before switching branches.
  3. Click Fetch origin to download the list of branches.
  4. Click Current branch. Search for walkthrough/3 and select it.
  5. Check that Current branch says walkthrough/3. If you see Pull origin, click it.
  6. Open Current branch → New branch. Name your working branch lab/your-name-elevator-levels, using your own name.
  7. Under Create branch based on…, choose walkthrough/3. Click Create branch.
  8. Open the Code2027-Preseason project using WPILib 2027 VS Code. Remember to open the top-level folder.

Screenshot placeholder: select walkthrough/3, then create your working branch from it.

The walkthrough branch contains the TODOs. Your working branch is where you save your edits.

Before editing

  • Alt + Tab: switch between this page and VS Code.
  • Ctrl + S: save your file.
  • Find the numbered TODO comment, then make the code match “After.” Remove that TODO as you finish; keep the later TODOs.

If the code does not match, check your branch. Some red underlines are normal until you finish the related edits.
