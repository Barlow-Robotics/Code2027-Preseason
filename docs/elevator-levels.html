Download the code and create your branch

Coach: publish before class

The starting tag is local only. Publish it and these pages before students begin.

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit your current work before switching branches.
  3. Under Current branch, choose main.
  4. Click Fetch origin. If it changes to Pull origin, click that too.
  5. Open History. Find tag walkthrough-03-start on Express elevator motion limits in meters (16d099e).
  6. Right-click that commit. Choose Create branch from commit.
  7. Name it lab/your-name-elevator-levels. Use your own name, then click Create branch.
  8. Open the Code2027-Preseason project using WPILib 2027 VS Code. Remember to open the top-level folder.
