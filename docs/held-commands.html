Setup

What we will build

Hold a button to move. Release it to stop and hold.

We will edit the elevator. Both mechanisms are already included.

Copying code into VS Code

Copy added code copies just the green lines, including their indentation.

  1. Click the copy button below the code.
  2. In VS Code, put your cursor at the very beginning of the destination line, before any spaces.
  3. Press Ctrl + V. Do not add spaces first—the copied code already includes them.

Replacing old code? Select those whole lines, including their leading spaces, before pasting.

Download the code and create your branch

Coach: publish before class

The starting tag is local only. Publish it and these pages before students begin.

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit your current work before switching branches.
  3. Under Current branch, choose main.
  4. Click Fetch origin. If it changes to Pull origin, click that too.
  5. Open History. Find tag walkthrough-02-start on Show creating a student branch from the tagged commit (76205fb).
  6. Right-click that commit. Choose Create branch from commit.
  7. Name it lab/your-name-held-commands. Use your own name, then click Create branch.
  8. Open the Code2027-Preseason project using WPILib 2027 VS Code. Remember to open the top-level folder.

Before editing
