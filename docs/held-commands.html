New in this tutorial: copying code

Copy added code copies just the green lines, including their indentation. Try adding them inside this example class.

public class Elevator {
    // Elevator target, in meters.
    double targetMeters = 0.65;
    boolean movementActive = false;
}
  1. Click Copy added code.
  2. Find the blank line just after the opening brace. It already has four spaces. Put your cursor at the very beginning, before those spaces.
  3. Press Ctrl + V. Keep the existing code around it.

Hint: try double-clicking in the whitespace to select it. When you paste, it will replace the selection.

Use the same steps in VS Code. Replacing old code? Select those whole lines, including their leading spaces, before pasting.

Download the code and create your branch

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit your current work before switching branches.
  3. Click Fetch origin to download the list of branches.
  4. Click Current branch. Search for walkthrough/2 and select it.
  5. Check that Current branch says walkthrough/2. If you see Pull origin, click it.
  6. Open Current branch → New branch. Name your working branch lab/your-name-held-commands, using your own name.
  7. Under Create branch based on…, choose walkthrough/2. Click Create branch.
  8. Open the Code2027-Preseason project using WPILib 2027 VS Code. Remember to open the top-level folder.

The walkthrough branch contains the TODOs. Your working branch is where you save your edits.

Before editing

  • Alt + Tab: switch between this page and VS Code.
  • Ctrl + S: save your file.
  • Find the numbered TODO comment, then make the code match “After.” Remove that TODO as you finish; keep the later TODOs.

Old code may show red underlines while we replace it. We will define new classes and methods before using them.
