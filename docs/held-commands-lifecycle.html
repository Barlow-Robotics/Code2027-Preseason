Command lifetime

What is a Command?

A command is a task the robot can start and stop. Ours is “move the elevator.”

Last time, we used runOnce to create a built-in command: do one action, then finish.

This time, we’ll extend the Command base class to write our own command. We choose what happens when it starts and stops.

WPILib’s scheduler manages the task by calling these methods:

initialize()
Start the task. Called once.
execute()
Do ongoing work. Called repeatedly while running.
isFinished()
Is the task done yet?
end(...)
Clean up when finished or canceled.

We do not need execute here: the Talon keeps controlling the motor after receiving its target.

A requirement reserves a subsystem. Only one scheduled command can require the elevator at a time.

Read more: WPILib command documentation

6. Add the private command class

Open src/main/java/first/robot/subsystems/Elevator.java. Find this code:

Before — red marks the code being changed

    public Command setHeightGoalCommand(double goal) {
        return runOnce(() -> setHeightGoal(goal));
    }

Keep the factory method. Add this private class directly below it.

After — green marks the added code

    public Command setHeightGoalCommand(double goal) {
        return runOnce(() -> setHeightGoal(goal));
    }

    private final class MoveToHeightCommand extends Command {
        private final double goal;

        private MoveToHeightCommand(double goal) {
            this.goal = goal;
            addRequirements(Elevator.this);
        }

        @Override
        public void initialize() {
            movementActive = true;
            setHeightGoal(goal);
        }

        @Override
        public boolean isFinished() {
            return false;
        }

        @Override
        public void end(boolean interrupted) {
            stopAndHold();
            movementActive = false;
        }
    }
  • goal remembers the destination.
  • addRequirements(Elevator.this) gives this command control of the elevator.
  • initialize starts the trip; end stops and holds.
  • isFinished returns false: keep running until canceled.

7. Use the new command in the factory

Open src/main/java/first/robot/subsystems/Elevator.java. Find this code:

Before — red marks the code being changed

    public Command setHeightGoalCommand(double goal) {
        return runOnce(() -> setHeightGoal(goal));
    }

Change the factory to return our new command.

After — green marks the added code

    public Command setHeightGoalCommand(double goal) {
        return new MoveToHeightCommand(goal);
    }
  • A factory is a method that creates an object.
  • Creating the command does not start it. The button will do that.
