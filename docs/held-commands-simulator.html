Try it

Open the simulator and graph

  1. Save your files. Stop any running simulator.
  2. In VS Code, press Ctrl + Shift + P. Choose WPILib: Simulate Robot Code, then Sim GUI.
  3. Connect the Xbox controller. Drag it from System Joysticks onto Joystick[1].
  4. Open AdvantageScope (WPILib). Choose File → Connect to Simulator, then NetworkTables if asked.
  5. Add a Line Graph. Expand Telemetry → Elevator.
  6. Drag in Target_m, Actual_m, MovementActive, and Velocity_mps.
  7. In Sim GUI, select Teleoperated and Enabled.

Need help finding the controls? See the screenshots.

Release before arrival

  1. Hold Y for two seconds, then release. The elevator should stop partway up and hold.
  2. Watch the graph. MovementActive becomes false. Target_m moves to the hold position.
  3. Tap B. The arm moves; the elevator stays put.
  4. Hold Y until arrival. MovementActive stays true until you release.
  5. Hold A, then release midway. It should hold again.

Try an interruption

  1. Hold Y. Keep holding it and press A.
  2. The elevator switches to moving down.
  3. Release A. It holds, even though Y is still held.
  4. Release Y, then press it again. Movement restarts.

Takeaway: both release and replacement call end to stop and hold.

Save your work

  1. Disable the simulator.
  2. In GitHub Desktop, open Changes and review your edits.
  3. Enter a short summary. Click Commit to save on your branch.
  4. Click Publish branch to share it with your coach.
