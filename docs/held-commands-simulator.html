Try it

Open the simulator and graph

  1. Save all files. If a simulator is already running, stop it before starting the new code.
  2. In VS Code, press Ctrl+Shift+P. Choose WPILib: Simulate Robot Code, then Sim GUI if prompted.
  3. Connect the Xbox controller. In System Joysticks, drag it onto Joystick[1]. This is the operator controller. Leave the robot disabled while arranging the windows.
  4. Open AdvantageScope (WPILib). Choose File → Connect to Simulator, selecting NetworkTables if prompted.
  5. Add a Line Graph tab. Expand Telemetry → Elevator and drag Target_m and Actual_m into the graph. Add MovementActive to see when the command is running; add Velocity_mps to see its motion.
  6. In the Sim GUI, select Teleoperated and Enabled.

If you need help locating these controls, see the first walkthrough’s simulator instructions.

Release before arrival

  1. Hold Y for about two seconds, then release it. Actual_m should rise partway toward 0.65 m.
  2. At release, MovementActive becomes false and Target_m changes to the measured hold position. Actual_m should settle there, with only a small amount of movement.
  3. Tap B to move the arm. The elevator should keep holding its position.
  4. Hold Y again until the elevator reaches the top. MovementActive stays true until you release it.
  5. Hold A to return downward. Release midway and watch it hold again.

Screenshot placeholder: one upward move with a mid-travel release, showing Target_m, Actual_m, and MovementActive. Keep the visible trace short.

Try an interruption

Hold Y, then press A while still holding Y. A takes ownership and moves downward. Release A: the elevator holds. Y does not restart automatically, even though it is still held. Release Y and press it again to request another move.

This demonstrates why cleanup belongs inside the command: both release and replacement use the same end method. The button binding only chooses when to schedule or cancel it.

Save your work

Disable the simulator. In GitHub Desktop, open Changes, review your three changed Java files, enter a summary such as “Move elevator while held,” and click Commit to your branch. Click Publish branch if you want to share it with your coach.
