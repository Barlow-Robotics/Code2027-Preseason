Levels

Y: increase. A: decrease.

BOTTOM (0 m) → MID (0.35 m) → TOP (0.65 m)

What is an Enum?

An enum gives a value a fixed set of named choices.

enum Level { BOTTOM, MID, TOP }

A Level can be BOTTOM, MID, or TOP—not an unrelated number or a misspelled name.

Our version will attach a height to each choice. Selecting TOP means “go there,” not “we have arrived.”

Read this example; you’ll add the full version below.

1. Name three destinations

Open src/main/java/first/robot/Constants.java. Find this code:

Before — red marks the code being changed

        public static final double LOW_METERS = 0.0;
        public static final double HIGH_METERS = 0.65;

Replace the elevator presets. Leave ArmConstants alone.

After — green marks the added code

        public static final double BOTTOM_METERS = 0.0;
        public static final double MID_METERS = 0.35;
        public static final double TOP_METERS = 0.65;
        public static final double POSITION_TOLERANCE_METERS = 0.01;
        public static final double VELOCITY_TOLERANCE_METERS_PER_SECOND = 0.02;
  • BOTTOM = 0 m. MID = 0.35 m. TOP = 0.65 m.
  • Arrived means within 1 cm of the goal AND moving slower than 2 cm/s.

2. Describe the levels with an enum

Open src/main/java/first/robot/subsystems/Elevator.java. Find this code:

Before — red marks the code being changed

public final class Elevator extends SubsystemBase {
    private final ElevatorSim sim = new ElevatorSim();

Add Level just inside the Elevator class, above sim.

After — green marks the added code

public final class Elevator extends SubsystemBase {
    public enum Level {
        BOTTOM(ElevatorConstants.BOTTOM_METERS),
        MID(ElevatorConstants.MID_METERS),
        TOP(ElevatorConstants.TOP_METERS);

        private final double heightMeters;

        Level(double heightMeters) {
            this.heightMeters = heightMeters;
        }

        public Level increase() {
            return switch (this) {
                case BOTTOM -> MID;
                case MID, TOP -> TOP;
            };
        }

        public Level decrease() {
            return switch (this) {
                case TOP -> MID;
                case MID, BOTTOM -> BOTTOM;
            };
        }
    }

    private final ElevatorSim sim = new ElevatorSim();
  • Each level stores its height.
  • increase() and decrease() return the neighboring level.
  • At TOP or BOTTOM, another step in that direction stays there.

3. Remember the selection

Open src/main/java/first/robot/subsystems/Elevator.java. Find this code:

Before — red marks the code being changed

    private double targetMeters = ElevatorConstants.LOW_METERS;

Replace targetMeters with these two fields.

After — green marks the added code

    private Level selectedLevel = Level.BOTTOM;
    private double targetMeters = ElevatorConstants.BOTTOM_METERS;
  • selectedLevel: the destination we last requested.
  • targetMeters: the motor’s current target, including a hold position.
  • Neither tells us where the elevator actually is. Read Actual_m for that.
