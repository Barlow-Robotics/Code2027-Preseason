Define the 3 levels

To define the levels, we’ll use an Enum.

What is an Enum?

An enum gives a value a fixed set of named choices: BOTTOM, MID, or TOP.

Each choice can carry a value

We use a valued enum: each level stores its height in meters.

public enum Level {
    BOTTOM(ElevatorConstants.BOTTOM_METERS),
    MID(ElevatorConstants.MID_METERS),
    TOP(ElevatorConstants.TOP_METERS);

    private final double heightMeters;

    Level(double heightMeters) {
        this.heightMeters = heightMeters;
    }
}
  • MID(...) passes MID’s height to the enum’s constructor—the setup code for that choice.
  • this.heightMeters = heightMeters saves that height inside the choice.
  • level.heightMeters reads the height for the selected level.

We choose a name like MID; the movement code uses its stored height. Selecting MID does not mean we have arrived.

/** Desktop elevator for the preseason controls lesson. */
public final class Elevator extends SubsystemBase {
    public enum Level {
        BOTTOM(ElevatorConstants.BOTTOM_METERS),
        MID(ElevatorConstants.MID_METERS),
        TOP(ElevatorConstants.TOP_METERS);

        private final double heightMeters;

        Level(double heightMeters) {
            this.heightMeters = heightMeters;
        }

        public Level increase() {
            return switch (this) {
                case BOTTOM -> MID;
                case MID, TOP -> TOP;
            };
        }

        public Level decrease() {
            return switch (this) {
                case TOP -> MID;
                case MID, BOTTOM -> BOTTOM;
            };
        }
    }

    private final ElevatorSim sim = new ElevatorSim();
  • Each level stores its height.
  • increase() and decrease() return the neighboring level.
  • At TOP or BOTTOM, another step in that direction stays there.
