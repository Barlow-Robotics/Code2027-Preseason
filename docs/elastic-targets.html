Change a target without rebuilding

What are we building?

Change a height or angle in Elastic. Press the same controller button. The mechanism travels to your new position—without rebuilding the robot code.

Choose your mechanism

Example: change MID from 0.35 m to 0.25 m. Press Y from BOTTOM to try it.

Example: change HIGH from 65° to 40°. Press B to try it.

Meet Elastic and NetworkTables

Elastic is a dashboard: a window of controls and readouts for the robot.

NetworkTables carries named values between the robot and dashboard. You already used it to watch position in AdvantageScope. This time we will send numbers back.

WPILib 2027 uses Tunables for editable values. Elastic replaces Shuffleboard in this lesson.

Download the code and create your branch

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit any current work before switching branches.
  3. Click Fetch origin.
  4. Click Current branch. Search for walkthrough/4 and select it. If you see Pull origin, click it.
  5. Open Current branch → New branch. Name it lab/your-name-elastic-targets. Under Create branch based on…, select walkthrough/4. Click Create branch.
  6. Open the Code2027-Preseason project in WPILib 2027 VS Code. Remember to open the top-level folder.
