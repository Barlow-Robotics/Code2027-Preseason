Repeat presses

Keep the elevator code. Change the buttons to create a fresh movement on each press.

10. Import the command builders

Open src/main/java/first/robot/RobotContainer.java. Find this code:

Before — red marks the code being changed

import org.wpilib.command2.Command;

Add Commands beside the existing Command import.

After — green marks the added code

import org.wpilib.command2.Command;
import org.wpilib.command2.Commands;
  • Commands.runOnce builds a command that performs one action, then finishes.

11. Start a fresh movement on each press

Open src/main/java/first/robot/RobotContainer.java. Find this code:

Before — red marks the code being changed

        operator.a().onTrue(elevator.decreaseLevelCommand());
        operator.y().onTrue(elevator.increaseLevelCommand());

Replace the two elevator button bindings.

After — green marks the added code

        operator.a().onTrue(Commands.runOnce(() ->
            CommandScheduler.getInstance().schedule(elevator.decreaseLevelCommand())));
        operator.y().onTrue(Commands.runOnce(() ->
            CommandScheduler.getInstance().schedule(elevator.increaseLevelCommand())));
  • runOnce runs the arrow’s code on each press.
  • That code creates a fresh movement command and schedules it.
  • The new movement replaces the old one. Nothing is queued.
  • Do not give runOnce an elevator requirement. The movement command owns it.

Try the same experiment again

  1. Save and restart the simulator. Reconnect AdvantageScope and enable Teleoperated mode.
  2. From BOTTOM: tap Y, wait one second, tap Y. Selection now reaches TOP before arrival at MID.
  3. From TOP: tap A, wait one second, tap A. Selection reaches BOTTOM.
  4. Hold Y from BOTTOM. It selects MID only once. Release and press again for TOP.

MovementActive may stay true during replacement. Watch SelectedHeight_m to see the new destination.

Screenshot placeholder: two Y presses during one trip.

Two different command lifetimes

  • Button command: starts the movement, then finishes.
  • Movement command: runs until arrival or interruption.

Ending the button command does not stop the movement it started.

For later: waiting in a sequence

Use goToLevelCommand directly when the next action must wait for arrival. Do not wrap it in the button’s runOnce pattern. Interrupting the movement still runs its cleanup.
