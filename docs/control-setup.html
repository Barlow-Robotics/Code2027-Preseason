What are we adding?

Five editable gains in Elastic, an Apply switch, and a new ProfileTarget trace in AdvantageScope.

Targets from walkthrough 4 still work. This time, applying a gain can change the motor’s behavior immediately—even during a movement or while holding.

Download the code and create your branch

  1. Open GitHub Desktop. Select Code2027-Preseason under Current repository.
  2. Save and commit any current work before switching branches.
  3. Click Fetch origin.
  4. Click Current branch. Search for walkthrough/5 and select it. If you see Pull origin, click it.
  5. Open Current branch → New branch. Name it lab/your-name-control-tuning. Under Create branch based on…, select walkthrough/5. Click Create branch.
  6. Open the Code2027-Preseason project in WPILib 2027 VS Code. Remember to open the top-level folder.

This branch starts with the completed walkthrough 4 and the TODOs for this lesson.
